Local-first multi-agent workspace

把 Agent 拉进
同一个任务现场。

Joi 不是新的 Agent。它是人、Claude/Codex、CI 服务和审批动作之间的协作层： 谁接手、看哪段上下文、执行到哪一步、产物在哪里，都留在同一个 workspace。

下载 Desktop / install.sh 启动本地工作台
joi-server --bind 127.0.0.1:8787 joi daemon --server http://127.0.0.1:8787
Joi Desktop
01 明确交接

handoff 让任务从人交给 router、discovery、delivery 或 service，不靠聊天记录猜责任人。

02 本机执行

server 只记录协作事实；Agent 仍在自己的机器、目录和权限边界里执行。

03 审批留痕

部署、删除、外部调用这类副作用进入 Inbox，批准或拒绝都会回到任务现场。
